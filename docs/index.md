Este sitio documenta un proyecto de integración numérica que utiliza la **cuadratura de Gauss** para aproximar integrales definidas. Como caso de estudio, se evalúa la siguiente integral:

\[
\int_0^\pi \sin(x^2) \, dx
\]

Este tipo de integral no tiene una solución analítica, por lo que los métodos numéricos como la cuadratura de Gauss resultan ideales.
