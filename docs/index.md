# Cuadratura Gaussiana

Este sitio documenta un proyecto de integración numérica que emplea la **cuadratura de Gauss** para la aproximación de integrales definidas. Como ejemplo práctico, se resuelve la siguiente integral:

\[
\int_0^\pi \sin(x^2) \, dx
\]

Esta integral no tiene una solución cerrada en términos de funciones elementales, lo que hace que métodos numéricos como la cuadratura de Gauss sean herramientas adecuadas para su evaluación.
